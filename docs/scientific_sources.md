# Scientific sources and implementation claims

This page records what the cited papers support and how that evidence relates to the current implementation. siRNAforge scores rank candidates under declared experimental weights; they do not predict a knockdown percentage, establish clinical safety, or replace an experiment. See [scoring.md](scoring.md) for the active terms, weights, and evidence status.

## How these ideas map to siRNAforge

- The current `design_experimental_v1` vector combines guide/passenger thermodynamic asymmetry, target accessibility, and GC content. Its weights are declared expert priors, not values fitted or independently validated by the cited papers. Each run records the vector and weights in its manifest. See [scoring.md](scoring.md) and [models_and_scoring.md](models_and_scoring.md).
- Target accessibility is computed from RNAplfold-derived unpaired probabilities. The scored quantity is the probability that the target site's 3′-end 8 nt, paired to guide positions 1–8, are unpaired. This is an implementation choice informed by retrospective association, not a claim that RNAplfold predicts cellular accessibility or potency. The RNAplfold algorithm is described by Bernhart et al. (2006), [“Local RNA base pairing probabilities in large sequences”](https://pubmed.ncbi.nlm.nih.gov/16368769/), PMID 16368769, DOI [10.1093/bioinformatics/btk014](https://doi.org/10.1093/bioinformatics/btk014).
- Off-target screens report the scope and references actually scanned. The transcriptome screen uses short-read alignment (BWA-MEM2) against configured transcript FASTAs, while the miRNA screen tests guide-seed matches against its configured database; these are distinct screens with different interpretations. Their output is evidence about matches under those references and rules, not a comprehensive biological safety assessment. A skipped screen or absent reference cannot be interpreted as zero off-target risk. See {ref}`workflows.md <nextflow-pipeline>` for screen scope and outputs.
- No paper listed above validates a candidate-specific efficacy, dose, toxicity, or clinical outcome from the current score. Use appropriately controlled laboratory assays for those conclusions.

## Citation audit notes

The titles, PMID, and DOI values above were checked against PubMed records. The DOI links are provided for persistent publisher identifiers. The former GAA example's bare `c.428A>G` notation is not a unique variant identity: ClinVar has records using that coding change for other genes (for example, [RAD51C](https://www.ncbi.nlm.nih.gov/clinvar/variation/128205/) and [GCH1](https://www.ncbi.nlm.nih.gov/clinvar/variation/3343521/)). A coding change must include a gene and transcript accession/version, and a reproducible design input must resolve to one exact GRCh38 genomic allele and agree with the selected transcript/reference sequence.
